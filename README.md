## О чем проект

**Sky Watcher Twitch - это экспериментальный ИИ-ассистент для [Twitch](https://twitch.tv)**. Главный вектор проекта - не дать понять, что на противоположной стороне находится не человек. Умение к анализу стрима, впитыванию контекста, обратной связи в виде сообщений в чат. 

Проект создан для изучения и практики: мультимодальный анализ (текст + аудио + видео) в реальном времени и генерация связанного контента.

### Безопасность и соблюдение правил Twitch

- **Не является вредоносным ПО**: Бот не накручивает зрителей, не спамит, не генерирует оскорбления и не выполняет никаких скрытых действий.
- **Официальное API**: Все действия в чате идут через Twitch API с соблюдением rate limits. 
- **Контроль**: Оператор всегда рядом (активирован только 1 экземпляр) с возможностью в любое время остановить работу бота.
- **Временное хранение**: После деактивации или завершения `.bat` все данные, собранные со стрима, безвозвратно удаляются.

## Техническая часть

### Краткий принцип работы

1. **Активация**: Запуск `.bat` → бот переходит в режим "впитывания контекста".
2. **Сбор данных**:
   - **Чат** — логируются и фильтруются (отбор информативных сообщений).
   - **Аудио** — STT-расшифровка, выделение ключевых тем и настроения. Анализ звуков (смех, музыка), которые дают дополнительный контекст.
   - **Видео** — анализ визуальных событий.
3. **Генерация**: После понимания контекста (некоторого времени) ИИ пишет в чат.
